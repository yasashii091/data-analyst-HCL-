## Project overview
This beginner data-analytics project cleans and analyses 1,000 synthetic student records using Python, Pandas and NumPy.

## Main files
- `2026B02310165_Yash_Pandey_Student_Performance_Analysis_Executed.ipynb`: completed source notebook with outputs
- `02_student_performance_expanded_1000.csv`: raw/unclean input dataset
- `02_student_performance_cleaned_1000.csv`: clean dataset
- `02_student_performance_final_analysis_1000.csv`: final dataset with derived analysis columns

## Run instructions
1. Upload the notebook and raw dataset to Google Colab.
2. Replace the GitHub-link placeholder in the first Markdown and code cells.
3. Select Runtime > Run all.
4. Confirm all outputs are visible, then use File > Print > Save as PDF.
